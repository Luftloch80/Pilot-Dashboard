PilotDashboard

Crewliste als PDF

optional

Ersetzt bei Erfolg die Crew im Dashboard (z. B. für ein separates Briefing-PDF). Die Datei wird nur lokal im Browser gelesen, nicht hochgeladen.

MyTime-Roster

optional

Zeigt im Layover die Pickup-Zeit an. Der Link enthält deinen persönlichen MyTime-Schlüssel und wird lokal auf diesem Gerät gespeichert. api.lufthansa.com blockiert direkte Zugriffe aus dem Browser (CORS); der Abruf läuft deshalb über einen öffentlichen CORS-Proxy (corsproxy.io mit Schlüssel unten, sonst allorigins.win) - der Link wird also auch an diesen Drittanbieter übertragen, nicht nur an Lufthansa.

AeroDataBox

optional

Zeigt bei einem Flugzeugwechsel in der Transit-Zeile, wann die neue Maschine vom Flug davor ankommt. Der Schlüssel wird nur lokal auf diesem Gerät gespeichert und bei jeder Anfrage direkt an prod.api.market gesendet. Er verlässt dieses Gerät sonst nicht.

Lufthansa Developer API

optional

Zusätzliche Zeiten-/Status-Quelle für den eigenen Flug (nur bei Lufthansa-Konzernflügen). Liefert keine Flugzeugkennung - dafür bleibt AeroDataBox zuständig. Client-ID/-Secret werden nur lokal auf diesem Gerät gespeichert und bei jeder Anfrage direkt an api.lufthansa.com gesendet. Sie verlassen dieses Gerät sonst nicht.

Lufthansa Crew Login

optional

Für den geplanten MyTime-Ersatz (noch nicht angebunden). Meldet dich über Lufthansas eigene Crew-Login-Seite an (Nutzer-ID + RSA-Token) - diese App speichert kein Passwort, nur das danach erhaltene Token, nur lokal auf diesem Gerät.

OpenAirLog verbinden

Dein API-Schlüssel wird ausschließlich lokal auf diesem Gerät gespeichert (Browser-Speicher) und bei jeder Anfrage direkt an openairlog.de gesendet. Er verlässt dieses Gerät sonst nicht.
